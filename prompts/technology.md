# 기술 조사 Agent — 요구사항 B-3, C-1
대상 기술: DeepSeek-V2 MLA(SW), ITME(HW). 두 기술의 구현/성숙도를 서로 구분한다.
각 기술 원문에서 다음 6가지 질문의 근거를 확인한다. 자료가 없으면 근거 부족으로 표기한다.
1. 해결할 KV cache 문제와 적용 범위는 무엇인가?
2. 압축 또는 메모리 계층 확장의 핵심 동작 원리는 무엇인가?
3. 구현 및 실험 환경은 무엇인가?
4. 측정된 메모리/처리량/지연 결과와 실험 조건은 무엇인가?
5. 원문에 명시된 한계 및 도입 전제조건은 무엇인가?
6. 구현·검증·실제 운영의 공개 근거로 추정할 수 있는 TRL은 무엇인가?
ITME 베이스라인 비교 질문 1개에서만 InfiniGen과 CXL-PNM을 조회한다.
확인되지 않은 채택/TRL/정량 결과를 생성하지 않는다.
